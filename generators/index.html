Zero-Touch CSV Generator

CSV

Erfasst Geräte-Metadaten (Hersteller, Modell, Zero-Touch ID, Seriennummern, IMEIs) und exportiert sie im Android-Zero-Touch-Enrollment-Format.

  • IMEI-Format & Luhn-Prüfsumme werden geprüft
  • Zero-Touch ID immer Pflicht
  • SN und IMEI zeilenweise gepaart

Eloview CSV Generator

CSV

Wandelt Tab-getrennte Rohdaten (Franchise, Land, Referenz, Ort, Gerätetyp, Index, Seriennummer) in eine Eloview „Add Device"-CSV um.

  • Device Name wird automatisch generiert
  • Franchise wird auf Tag gemappt (z. B. Subway)
  • Fehlerhafte Zeilen werden übersprungen & markiert
Generator öffnen

Sunmi MSN Generator

XLSX

Erfasst eine Sunmi ID und zugehörige Seriennummern (MSN) und exportiert sie als XLSX-Datei, eine Zeile pro Seriennummer.

  • Seriennummern per Leerzeichen oder Zeilenumbruch
  • Sunmi ID + mind. 1 Seriennummer Pflicht
  • Duplikate werden markiert
